# NotesPHP
## A PHP Program that Creates, Looks Up and Deletes Notes:

It is a Terminal Based Program in which you have 6 Main Options:
### 1: Create Note
Create a .txt File by just Simply entering the Name, no need for entering the Datatype. It will be automaticly saved in the `Notes/` Folder this Program came with.

You can write as many Lines as you want, and to exit and save your Inputs, write `(exit)`.

### 2: View Note
To see your Note, put in the Name of your Note, without Datatype, (.txt) and it will be shown.

### 3: Delete Note
If you want to delete a Note you don't need, write the Name of the Note (No .txt needed again) and confirm the Deletion.

### 4: Infos of Note
To see Information of Your File

### 5: Search Patterns of Note
To Look for a Pattern that could be in a Note, enter the Pattern you are looking for. Inputting "/ /" is not needed. The Input is automaticly Case Insensitive.

### 6: List Notes
To see what Notes are in your `Notes/` Folder, pressing `6` is all you need.

### And to End the Program, just press `7`!
